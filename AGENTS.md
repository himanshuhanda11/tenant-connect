# Project rules

- Workspace-scoped Meta (Facebook) data syncs (lead forms, pages, leads) must use only that workspace's own connected token from `smeksh_meta_ad_accounts`; never fall back to the platform `META_SYSTEM_USER_TOKEN`. Why: the platform token belongs to another business and leaks its Pages/forms into unconnected workspaces.
- Facebook tokens are server-only: browsers never receive, send or store them. Connect/reconnect/refresh/save go through the `meta-ads-fb-login` edge function (pending tokens in `meta_oauth_pending`), and the browser selects `smeksh_meta_ad_accounts` only via `META_AD_ACCOUNT_PUBLIC_COLUMNS` (column privileges block `meta_access_token` and `select('*')`). Why: any workspace member could previously read the token, and a browser-written Page ID could route another business's leads.
- Meta connection problems are classified by `supabase/functions/_shared/metaAdsDiagnosis.ts` (unit-tested in `src/test/meta-ads-diagnosis.test.ts`); add new causes there instead of ad-hoc UI messages. Why: one source of truth for customer-facing recovery steps.
- A workspace keeps one active WhatsApp number. Replacing or disconnecting a number goes through `supabase/functions/_shared/whatsappNumberRelease.ts` (deregister in Meta, unsubscribe the WABA only when no active number still uses it, keep the row as `disconnected`, move chats/flows to the new number); never delete `phone_numbers` rows. Why: deletes cascade away campaign history, and label-only disconnects left numbers registered in Meta. Unit-tested in `src/test/whatsapp-number-release.test.ts`.
- Ad-based lead routing for Click-to-WhatsApp chats targets the WhatsApp `referral.source_id` stored in `meta_ctwa_ads` (filled by the webhook via `record_ctwa_ad_click`) and saved on automations as `trigger_conditions.meta_ad_ids`; matching lives in `supabase/functions/_shared/metaAdTargeting.ts` (tested in `src/test/meta-ad-targeting.test.ts`), and ad automations run before general auto-routing. Why: workspaces without Meta ad-account access still need per-ad distribution, and ad-specific assignment must win over the workspace round robin.
